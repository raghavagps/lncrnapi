# 🧬 lncrna-PI — LncRNA–Protein Interaction Prediction

**lncrna-PI** is a command-line tool for predicting **lncRNA–protein interactions** using sequence-derived features and a **CatBoost classifier**.

The tool supports two prediction methods:

* **Rapid** — a fast, lightweight composition-based method using lncRNA nucleotide composition and protein amino-acid composition.
* **DACC + ESM-2 t30** — the primary embedding-based method using **DACC features for lncRNAs** and **ESM-2 t30 embeddings for proteins**.

For both methods, the tool performs **all-by-all prediction** between every lncRNA and every protein sequence provided in the input FASTA files.

## 📦 Features

* Command-line interface for lncRNA–protein interaction prediction
* FASTA-based input for lncRNA and protein sequences
* All-by-all lncRNA–protein pairing
* Automatic feature generation
* Two prediction methods:

  * **Rapid:** nucleotide and amino-acid composition features
  * **DACC + ESM-2 t30:** DACC features + protein language model embeddings
* GPU-aware ESM-2 embedding generation
* Automatic fallback to CPU when GPU acceleration is unavailable
* User-defined probability threshold for interaction classification
* Reports both predicted interaction probability and interaction label
* Validation of feature dimensions and model compatibility

# 🔬 Prediction Methods

## 1. Rapid — Composition-Based Method

The **Rapid** method uses simple sequence-composition features and is designed for fast prediction with minimal computational requirements.

### lncRNA features

The lncRNA sequence is converted from RNA to DNA alphabet where required (`U → T`) and four nucleotide composition features are calculated:

* `CDK_A`
* `CDK_T`
* `CDK_G`
* `CDK_C`

Each feature represents the percentage composition of the corresponding nucleotide.

### Protein features

Ten amino-acid composition features are calculated:

* `AAC_G`
* `AAC_Q`
* `AAC_Y`
* `AAC_N`
* `AAC_R`
* `AAC_L`
* `AAC_C`
* `AAC_W`
* `AAC_T`
* `AAC_V`

This produces a total of **14 features per lncRNA–protein pair**.

The resulting feature vector is passed to the Rapid CatBoost classifier.

**Model:**

```text
models/catboost_model_rapid.joblib
```

---

## 2. DACC + ESM-2 t30

The **DACC + ESM-2 t30** method uses DACC features for lncRNAs and ESM-2 t30 embeddings for proteins.

### lncRNA features

DACC features are calculated using:

```text
calc_DACC.py
```

The method generates **288 DACC features** for each lncRNA.

### Protein features

Protein sequences are embedded using:

```text
facebook/esm2_t30_150M_UR50D
```

The protein embedding is generated by mean pooling the residue-level hidden representations, resulting in a **640-dimensional embedding**.

Therefore, each lncRNA–protein pair is represented by:

```text
288 DACC features
+
640 ESM-2 features
-------------------
928 total features
```

The resulting 928-dimensional feature vector is passed to the CatBoost classifier.

**Model:**

```text
model/catboost_final_model_full.cbm
```

# ⚙️ Usage

## 1️⃣ Rapid Prediction

The Rapid method uses composition-based features and does not require ESM-2.

```bash
python lncrnapi_cli.py \
    -ln ./data/example_lncRNA.fasta \
    -pr ./data/example_protein.fasta \
    -wd ./output \
    --model rapid
```

The default classification threshold is:

```text
0.5
```

To specify a custom threshold:

```bash
python lncrnapi_cli.py \
    -ln ./data/example_lncRNA.fasta \
    -pr ./data/example_protein.fasta \
    -wd ./output \
    --model rapid \
    --threshold 0.7
```

**Model used:**

```text
models/catboost_model_rapid.joblib
```

---

## 2️⃣ DACC + ESM-2 t30 Prediction

The DACC + ESM-2 t30 method calculates DACC features for the lncRNAs and ESM-2 t30 embeddings for the proteins.

```bash
python lncrnapi_cli.py \
    -ln ./data/example_lncRNA.fasta \
    -pr ./data/example_protein.fasta \
    -wd ./output \
    --model dacc_esm2_t30
```

With a custom threshold:

```bash
python lncrnapi_cli.py \
    -ln ./data/example_lncRNA.fasta \
    -pr ./data/example_protein.fasta \
    -wd ./output \
    --model dacc_esm2_t30 \
    --threshold 0.7
```

**Model used:**

```text
model/catboost_final_model_full.cbm
```

# 📋 Command-Line Arguments

| Argument | Long form             | Description                                             | Required |                  Default |
| -------- | --------------------- | ------------------------------------------------------- | :------: | -----------------------: |
| `-ln`    | `--lncrna_fasta`      | Path to the lncRNA FASTA file                           |     ✅    |                        — |
| `-pr`    | `--protein_fasta`     | Path to the protein FASTA file                          |     ✅    |                        — |
| `-wd`    | `--working_directory` | Working directory for intermediate and output files     |     ❌    |                     `./` |
| `-o`     | `--output_file`       | Name/path of the final prediction CSV                   |     ❌    | `prediction_results.csv` |
| `-m`     | `--model`             | Prediction method: `rapid` or `dacc_esm2_t30`           |     ❌    |          `dacc_esm2_t30` |
| `-t`     | `--threshold`         | Probability threshold used to assign interaction labels |     ❌    |                    `0.5` |

---

# 🎚️ Classification Threshold

The `--threshold` argument determines how the predicted interaction probability is converted into a binary interaction label.

The threshold must be between **0 and 1**.

For each lncRNA–protein pair:

```text
Interaction Probability >= Threshold
                    ↓
               Interacting
```

and:

```text
Interaction Probability < Threshold
                    ↓
             Non-interacting
```

For example, with:

```bash
--threshold 0.7
```

a predicted probability of `0.82` is classified as:

```text
Interacting
```

while a probability of `0.63` is classified as:

```text
Non-interacting
```

# 💾 Output

The tool generates a CSV file in the specified working directory.

By default:

```text
prediction_results.csv
```

The output contains four columns:

| LncRNA_ID | Protein_ID | Interaction_Probability | Predicted_Label |
| --------- | ---------- | ----------------------: | --------------- |
| lnc1      | P12345     |                  0.8734 | Interacting     |
| lnc1      | P67890     |                  0.2147 | Non-interacting |
| lnc2      | P12345     |                  0.6211 | Interacting     |

### Output columns

**`LncRNA_ID`**

Identifier of the lncRNA sequence from the input FASTA file.

**`Protein_ID`**

Identifier of the protein sequence from the input FASTA file.

**`Interaction_Probability`**

Probability of interaction predicted by the CatBoost classifier.

**`Predicted_Label`**

Classification based on the user-defined threshold:

* `Interacting`
* `Non-interacting`

# 🔄 Prediction Workflow

## Rapid

```text
lncRNA FASTA
     │
     ├── Nucleotide composition
     │       └── 4 CDK features
     │
Protein FASTA
     │
     ├── Amino-acid composition
     │       └── 10 AAC features
     │
     └──────────────┬──────────────┘
                    ↓
              14 features
                    ↓
             CatBoost model
                    ↓
       Interaction probability
                    ↓
          User-defined threshold
                    ↓
      Interacting / Non-interacting
```

## DACC + ESM-2 t30

```text
lncRNA FASTA
     │
     ├── DACC calculation
     │       └── 288 features
     │
Protein FASTA
     │
     ├── ESM-2 t30
     │       └── 640-dimensional embedding
     │
     └──────────────┬──────────────┘
                    ↓
              928 features
                    ↓
             CatBoost model
                    ↓
       Interaction probability
                    ↓
          User-defined threshold
                    ↓
      Interacting / Non-interacting
```

Both methods perform **all-by-all prediction**, meaning that every lncRNA is paired with every protein in the corresponding input FASTA files.

# ⚡ Hardware Acceleration

Hardware acceleration is used automatically for the **DACC + ESM-2 t30** method during ESM-2 embedding generation.

The tool checks for:

* ✅ **CUDA GPU** — NVIDIA GPUs
* ✅ **MPS** — Apple Silicon GPUs
* ⚠️ **CPU** — fallback when GPU acceleration is unavailable

The Rapid method does not require a GPU because it uses sequence-composition features.
